Shared Operations and Verbs

Functions that several packages of the stack implement or extend. They are defined once, here, so that every package adds methods to the same function instead of defining another function of the same name. The names can then be used unqualified whichever packages are loaded together.

Kernels, matrices and block matrices

Methods for the core types. IntegralProjectionModels.jl re-exports them, and CategoricalPopulationDynamics.jl extends them to its own domains, to projection nets and to Catlab's FinFunction.

StructuredPopulationCore.left_kan_extension — Function
left_kan_extension(kernel_fn, domain::ContinuousDomain)

Discretise a continuous kernel function kernel_fn(z_new, z) into a matrix using the midpoint rule on the given domain.

This is the left Kan extension along the discretisation functor: it maps a morphism in Krn (Markov kernels on measurable spaces) to a morphism in FinStoch (stochastic matrices on finite sets).

$A_{ij} = h \cdot K(z_i, z_j)$

where $h$ is the bin width and $z_i$ are the midpoints.

Arguments

  • kernel_fn: a callable (z_new, z) -> Real giving the kernel density
  • domain: a ContinuousDomain specifying bounds and mesh resolution

Returns

  • A::Matrix{Float64}: the discretised transition matrix

Keyword options (another quadrature rule, positivity) are implemented by CategoricalPopulationDynamics.jl; see discretise_kernel.

source
StructuredPopulationCore.discretise_kernel — Function
discretise_kernel(kernel_fn, domain; options...)

Extension point for left_kan_extension called with keyword options on a ContinuousDomain. The core package implements the midpoint rule only. CategoricalPopulationDynamics.jl adds the method that honours rule, ensure_nonneg and normalize_rows. Not exported.

source
StructuredPopulationCore.right_kan_extension — Function
right_kan_extension(A::AbstractMatrix, domain::ContinuousDomain)

Construct a piecewise-constant kernel function from a matrix and domain.

This is the right Kan extension: the most conservative continuous representation of a discrete transition matrix. The resulting kernel is constant within each bin pair:

$K_{\mathrm{pw}}(z', z) = A_{ij} / h \quad \text{where } z \in B_j,\; z' \in B_i$

Arguments

  • A: an n × n transition matrix
  • domain: a ContinuousDomain with n meshpoints matching size(A, 1)

Returns

  • A callable (z_new, z) -> Real giving the piecewise-constant kernel density

StructuredPopulationCore.stratify — Function
stratify(A_local::AbstractMatrix, coupling::AbstractMatrix)

Construct a block-structured matrix from a single local transition matrix and a coupling (dispersal) matrix. Every stratum (patch, genotype, infection state) shares the same local dynamics.

In the categorical framework, this is a pullback in a slice category: the local demography is replicated across strata and weighted by the coupling.

$A_{\mathrm{strat}}[(s_{\mathrm{to}}, i),\, (s_{\mathrm{from}}, j)] = D[s_{\mathrm{to}}, s_{\mathrm{from}}] \cdot A_{\mathrm{local}}[i, j]$

Arguments

  • A_local: an n × n local (single-stratum) transition matrix
  • coupling: a p × p matrix of weights between strata, coupling[to, from]

Returns

  • an (n·p) × (n·p) block-structured matrix
source
StructuredPopulationCore.coarsen — Function
coarsen(A::AbstractMatrix, from_domain::ContinuousDomain, to_domain::ContinuousDomain)

Coarsen a fine transition matrix to a coarser resolution by aggregating bins.

This is the pushforward (left Kan extension) along the coarsening map $f\colon \mathrm{FinSet}(n_{\mathrm{fine}}) \to \mathrm{FinSet}(n_{\mathrm{coarse}})$. Each coarse bin collects contributions from the fine bins it contains.

The from_domain and to_domain must share the same [lower, upper] bounds. The number of fine bins must be an integer multiple of the number of coarse bins.

Arguments

  • A: an n_fine × n_fine transition matrix
  • from_domain: the fine ContinuousDomain
  • to_domain: the coarse ContinuousDomain

Returns

  • an n_coarse × n_coarse transition matrix

StructuredPopulationCore.compose_from_uwd — Function
compose_from_uwd(uwd, sub_kernels::Dict, domain)

Evaluate a Catlab undirected wiring diagram (UWD) with concrete sub-kernels: each box is looked up by name in sub_kernels, and the composition sums their contributions on the mesh of domain.

The core package only declares the function. Methods are added where Catlab is available: by the Catlab extension of IntegralProjectionModels.jl for a ContinuousDomain, and by CategoricalPopulationDynamics.jl for its own domains.

Arguments

  • uwd: a Catlab UWD (from @relation)
  • sub_kernels: a Dict{Symbol, Function} mapping box names to kernel functions
  • domain: the domain to discretise on

Returns

  • the composed, discretised transition matrix

StructuredPopulationCore.set_state! — Function
set_state!(system, name, value)
set_state!(...)

Set a piece of the state that a model carries.

set_state!(system, name, value) sets the named auxiliary state of a PopulationSystem. If the entry is an AbstractStateVariable the call is passed on to set_state!(variable, value); otherwise the entry is replaced, or created. FiniteStatePopulationDynamics.jl adds set_state!(integrator, domain, label, value) for use in events.

Declared here so that these are one function. It is not exported from the core package: the packages that use it export it.

Coupled population systems

The data layer for systems of several named components with auxiliary state, scheduled events, interaction rules and observables. MatrixProjectionModels.jl and PhysiologicallyBasedDemographicModels.jl both build on it: they import these names, export them, and add the solver that steps a system. None of the names is exported from the core package.

A component carries its numbers in component.population. The core handles stage vectors. A package with another kind of carrier adds methods of total_population, inject!, remove_fraction! and as_component for it.

Components and systems

StructuredPopulationCore.PopulationComponent — Type
PopulationComponent(model, population; stage_names, species, type, patch)

A named stage-structured population component of a PopulationSystem.

  • model is what steps the component: a matrix, a model type of one of the packages, or a callable (system, day, p) -> AbstractMatrix. It is nothing when the carrier steps itself.
  • population is the carrier of the current numbers: a stage vector, or a carrier type of one of the packages.
  • species, type and patch carry grouping metadata.

This constructor is for a stage vector. The vector is copied and converted to floating point, and the model is checked against its length.

source
StructuredPopulationCore.PopulationSystem — Type
PopulationSystem(name => component, ...; state = NamedTuple())

Ordered collection of named PopulationComponents plus named auxiliary state exposed to rules, events and observables. A value that is not a component is wrapped with as_component.

state is a NamedTuple, a dictionary or a vector of pairs, whose values are copied; or a vector of AbstractStateVariables, which are stored by reference under their name.

Components are read with system[name], iterated in order with pairs(system), and state with get_state(system, name).

source
StructuredPopulationCore.AbstractStateVariable — Type
AbstractStateVariable

Supertype for named auxiliary state held in a PopulationSystem by reference and read or changed through get_state and set_state!. A package that defines a state variable type adds get_state(variable) and set_state!(variable, value) methods for it. Plain values (numbers, arrays, dictionaries) can be stored as state without a wrapper.

StructuredPopulationCore.inject! — Function
inject!(system, name, [stage,] amount)

Add amount individuals to a stage (the first by default) of the named component. The work is done by inject!(carrier, stage, amount). For a stage vector the amount must be nonnegative and the stage in range.

source
StructuredPopulationCore.remove_fraction! — Function
remove_fraction!(system, name, [stage,] fraction)

Remove a fraction of the individuals of the named component, from one stage or, without stage, from all of them. The work is done by remove_fraction!(carrier, [stage,] fraction). For a stage vector the fraction must be finite and lie in [0, 1].

Events, rules and observables

StructuredPopulationCore.AbstractScheduledEvent — Type
AbstractScheduledEvent

Supertype for events applied at the start of a time step on particular days (releases, sprays). apply_event!(event, system, day, p) returns true if the event fired.

apply_event!(event, system, day, p) -> Bool
