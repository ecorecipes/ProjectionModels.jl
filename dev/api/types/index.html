Types

Abstract and concrete types for classifying structured population projection models.

Top-level structure

StructuredPopulationCore.AbstractProjectionStructure — Type
AbstractProjectionStructure

Supertype for projection model structure traits. Subtypes include shared continuous-state structures plus package-specific specializations.

source
StructuredPopulationCore.AbstractContinuousStateStructure — Type
AbstractContinuousStateStructure

Shared supertype for continuous-state model structures. This is used by both discrete-time integral projection models and the forthcoming continuous-state continuous-time backends.

source
StructuredPopulationCore.AbstractIPMStructure — Type
AbstractIPMStructure

Compatibility supertype for the existing integral projection model structure names. It remains available as part of the shared abstraction layer so current IPM code can keep its API while new packages dispatch on the more neutral AbstractContinuousStateStructure.

source
StructuredPopulationCore.SimpleIPM — Type
SimpleIPM

Single continuous-state structure.

source
StructuredPopulationCore.GeneralIPM — Type
GeneralIPM

Multi-state or otherwise generalized continuous-state structure.

source
StructuredPopulationCore.SimpleContinuousState — Type
SimpleContinuousState

Alias of SimpleIPM. Use this name when writing code at the generic continuous-state-structure level (e.g., for finite-element or non-IPM continuous-state schemes).

source
StructuredPopulationCore.GeneralContinuousState — Type
GeneralContinuousState

Alias of GeneralIPM. Use this name when writing code at the generic multi-state continuous-state level.

source

Density dependence and stochasticity

StructuredPopulationCore.AbstractDensityDependence — Type
AbstractDensityDependence

Supertype for density dependence traits. Subtypes: DensityIndependent, DensityDependent.

source
StructuredPopulationCore.DensityIndependent — Type
DensityIndependent

Vital rates do not depend on population size or density.

source
StructuredPopulationCore.DensityDependent — Type
DensityDependent

Vital rates depend on current population size or density.

source
StructuredPopulationCore.AbstractStochasticity — Type
AbstractStochasticity

Supertype for stochasticity traits. Subtypes: Deterministic, StochasticKernelResampled, StochasticParameterResampled.

source
StructuredPopulationCore.Deterministic — Type
Deterministic

No stochastic variation; vital rates and kernels are fixed across time steps.

source
StructuredPopulationCore.StochasticKernelResampled — Type
StochasticKernelResampled

Environmental stochasticity via resampling entire kernel matrices at each time step.

source
StructuredPopulationCore.StochasticParameterResampled — Type
StochasticParameterResampled

Environmental stochasticity via resampling parameters that generate kernels at each time step.

source

Solver / analysis dispatch tags

StructuredPopulationCore.DirectIteration — Type
DirectIteration

Iterate the population forward via matrix multiplication: n_{t+1} = K * n_t.

source
StructuredPopulationCore.EigenAnalysis — Type
EigenAnalysis

Compute eigendecomposition of the materialized kernel matrix. No iteration is performed; returns asymptotic quantities directly.

source
StructuredPopulationCore.AbstractProjectionSolution — Type
AbstractProjectionSolution

Supertype for projection model solutions. Subtypes must have fields:

  • t: time steps
  • u: population states
  • kernel_matrices: materialized kernel(s)
  • eigenanalysis: named tuple (lambda, stable_dist, repro_value) or nothing
  • retcode: Symbol
  • lambdas: per-step growth rates
source

Delay-generator term

StructuredPopulationCore.DelayGeneratorTerm — Type
DelayGeneratorTerm(lag, operator)

A shared delayed linear contribution for continuous-time generator formulations. The operator may be a matrix or a callable returning one.

source

Transport discretizations

Shared by ContinuousStatePopulationDynamics.jl and PhysiologicallyBasedDemographicModels.jl, which export them. Not exported from the core package.

StructuredPopulationCore.AbstractTransportDiscretization — Type
AbstractTransportDiscretization

Supertype for the numerical methods that turn a transport equation over a continuous structuring variable (size, age, physiological age) into a system of ordinary differential equations.

Not exported from the core package: ContinuousStatePopulationDynamics.jl and PhysiologicallyBasedDemographicModels.jl import it and export it, the latter also under the name AbstractPSPMMethod.

source
StructuredPopulationCore.FixedMeshUpwind — Type
FixedMeshUpwind(; n_mesh = nothing)

First-order upwind method of lines on a fixed mesh.

n_mesh is the number of mesh cells. It is nothing when the mesh is given by the problem (the ContinuousDomain of a PSPMIPMProblem in ContinuousStatePopulationDynamics.jl) or left to the solving package's default (100 cells per species in PhysiologicallyBasedDemographicModels.jl).

Not exported from the core package: the packages that use it export it.
